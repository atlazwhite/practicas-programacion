# Generador de Frases Motivacionales o Memes

- **Concepto:** Una aplicación donde el usuario puede escribir un texto superior e inferior, seleccionar una imagen de fondo o categoría, y ver cómo se compone la tarjeta o "meme" en pantalla
- **Por qué funciona:** Familiariza al estudiante con la manipulación del texto interno de un elemento (`textContent`/`innerText`) y la modificación dinámica de atributos de imagen (`src`)
- **Elemento interactivo JS:** Campos de texto cuyas lecturas actualizan automáticamente el texto superpuesto sobre la imagen en tiempo real, junto con un botón para cambiar la imagen de fondo
