# Contador de Clics con Temporizador

- **Concepto:** Un botón grande y un contador en pantalla. Al hacer el primer clic, se inicia una cuenta regresiva de 10 segundos para ver cuántos clics logra hacer el usuario
- **Por qué funciona:** Enseña el uso de `setInterval` / `setTimeout` para manejar tiempo y eventos `click` repetitivos
- **Elemento interactivo JS:** Evento `click` que incrementa un contador visible y deshabilita el botón cuando el tiempo llega a cero
