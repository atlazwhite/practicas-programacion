# Conversor de Unidades Interactivo (Temperatura o Divisas Ficticias)

- **Concepto:** Una pequeña herramienta con dos campos de entrada y un menú desplegable para convertir grados Celsius a Fahrenheit/Kelvin, o monedas de videojuegos/fantasía (ej. monedas de oro a plata)
- **Por qué funciona:** Enseña la lectura de valores numéricos desde el DOM, el uso de selecciones (`<select>`) y la aplicación de fórmulas matemáticas sencillas en funciones
- **Elemento interactivo JS:** Evento `input` o `change` que realiza la conversión en tiempo real mientras el usuario escribe, y un botón "Limpiar" para restablecer los campos
