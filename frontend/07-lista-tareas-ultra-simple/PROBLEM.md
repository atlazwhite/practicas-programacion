# Lista de Tareas Ultrạ Simple

- **Concepto:** Un campo de texto y un botón "Agregar". Al escribir una tarea, esta se suma a una lista `<ul>`. Al hacer clic sobre cualquier tarea agregada, esta se marca como completada (tachada) o se elimina
- **Por qué funciona:** Es el "Hola Mundo" clásico de la manipulación del DOM (creación dinámica de nodos con `createElement` o `innerHTML`)
- **Elemento interactivo JS:** Evento `submit` / `click` para agregar elementos y escuchador en la lista para tachar/eliminar
