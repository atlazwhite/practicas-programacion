# Galería / Reproductor de Imágenes

- **Concepto:** Una tarjeta con una imagen central y dos botones: "Anterior" y "Siguiente", para navegar por una lista predefinida de URLs de imágenes
- **Por qué funciona:** Introduce el manejo de arreglos de cadenas de texto y la modificación directa del atributo `src` de una etiqueta `<img>`
- **Elemento interactivo JS:** Modificación del índice del arreglo con bordes circulares (si llega al final, vuelve al inicio)
