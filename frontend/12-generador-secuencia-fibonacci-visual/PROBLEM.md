# Generador de Secuencia de Fibonacci Visual

- **Concepto:** El usuario ingresa un número de elementos deseado (ejemplo: `8`) mediante un selector o slider, y la pantalla genera bloques o tarjetas cuadradas con la secuencia numérica de Fibonacci ($0, 1, 1, 2, 3, 5, 8, 13\dots$)
- **Por me funciona:** Muestra cómo una regla matemática interactúa con la creación y renderizado visual dinámico en el DOM
- **Elemento interactivo JS:** Un bucle o arreglo dinámico que genera los números de la serie e inserta pequeñas cajas CSS estilizadas por cada término generado
