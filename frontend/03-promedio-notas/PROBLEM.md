# Simulador de Promedio de Notas con Indicador de Estado

- **Concepto:** Una interfaz con 3 o 4 campos de entrada para ingresar calificaciones numéricas (ej. del 0 al 20 o del 1 al 10) y calcular el promedio final del estudiante
- **Por qué funciona:** Refuerza la conversión de texto a número (`parseFloat`/`parseInt`), operaciones aritméticas de promedio y la lógica condicional (`if/else`)
- **Elemento interactivo JS:** Un botón "Calcular" que muestra la nota final y cambia dinámicamente el color del contenedor (verde si aprobó, rojo si reprobó) mediante la modificación de clases CSS
