# Calculadora de Área y Perímetro de Rectángulo

- **Concepto:** Una pequeña interfaz interactiva con dos campos (`Base` y `Altura`) donde el usuario ingresa valores y la página calcula en tiempo real tanto el Área como el Perímetro del rectángulo
- **Por qué funciona:** Refuerza de manera visual la diferencia entre operaciones matemáticas básicas (Multiplicación vs. Suma) aplicadas a entradas del usuario
- **Elemento interactivo JS:** Eventos `input` que aplican las fórmulas ($A = b \times h$ y $P = 2b + 2h$) y actualizan directamente los valores en pantalla sin necesidad de recargar la página
