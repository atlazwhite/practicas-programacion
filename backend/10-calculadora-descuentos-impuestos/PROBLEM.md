# Calculadora de Descuentos e Impuestos

- **Concepto:** Un programa que solicita el precio base de un producto, un porcentaje de descuento opcional y un porcentaje de IVA/impuesto, devolviendo el desglose del costo final
- **Por qué funciona:** Enseña operaciones de punto flotante (`float`/`double`), redondeo de decimales para salida comercial y orden de operaciones matemáticas
- **Lógica clave:** Aplicar primero el descuento al precio base y luego calcular el impuesto sobre el subtotal resultante
