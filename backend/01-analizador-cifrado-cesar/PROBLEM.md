# Analizador de Texto y Cifrado César Simple

- **Concepto:** Una herramienta de consola donde el usuario ingresa una frase y el programa muestra estadísticas simples (número de palabras, cantidad de vocales) y genera una versión cifrada desplazando cada letra N posiciones
- **Por qué funciona:** Excelente para familiarizarse con la manipulación de arreglos de caracteres (`char[]`/`Strings`) y el código ASCII
- **Lógica clave:** Recorrido de cadenas con bucles `for` y operaciones aritméticas directas sobre caracteres
