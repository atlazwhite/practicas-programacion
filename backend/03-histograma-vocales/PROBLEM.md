# Formateador e Histograma de Frecuencia de Vocales

- **Concepto:** Una herramienta que lee una cadena de texto e imprime una representación visual básica (utilizando asteriscos `*`) con la cantidad de veces que aparece cada vocal ($a, e, i, o, u$)
- **Por qué funciona:** Introduce la estructura de arreglos de contadores (un arreglo de tamaño 5 para las vocales) y la impresión formateada por consola
- **Lógica clave:** Evaluar cada carácter con una estructura `switch` o múltiples `if`, e imprimir bucles secundarios para generar las barras de asteriscos (ej. `A: ****`).
