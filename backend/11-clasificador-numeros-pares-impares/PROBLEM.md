# Clasificador de Números Pares e Impares

- **Concepto:** Un programa que solicita al usuario ingresar una serie o lista de números (o un número límite $N$) e imprime cuántos números son pares, cuántos son impares y la suma total de cada grupo
- **Por qué funciona:** Trabaja el operador módulo/residuo (`% 2`) de forma directa y ejercita el uso de contadores y acumuladores numéricos en un bucle simple
- **Lógica clave:** Evaluar si `numero % 2 == 0` para incrementar el contador/acumulador correspondiente e imprimir un informe al finalizar
