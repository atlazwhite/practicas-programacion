# Contador de Palabras y Análisis de Frase

- **Concepto:** El usuario ingresa una línea de texto por consola y el programa imprime cuántas palabras contiene, la palabra más larga y la cantidad total de caracteres sin contar espacios
- **Por qué funciona:** Introduce el manejo básico de delimitadores de texto (separación por espacios) y la iteración para encontrar un valor máximo en longitud
- **Lógica clave:** Recorrido del string o división (`split`/lectura de tokens) comparando la longitud de cada palabra con una variable acumuladora
