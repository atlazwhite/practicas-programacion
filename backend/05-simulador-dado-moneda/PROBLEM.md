# Simulador de Dato / Moneda

- **Concepto:** Un programa de consola que le permite al usuario elegir entre "Lanzar Moneda" (Cara/Sello) o "Lanzar Dado" (1 al 6), mostrando el resultado por pantalla
- **Por qué funciona:** Muy rápido de codificar; ideal para entender la generación de números aleatorios y condicionales `if-else` / `switch`
- **Lógica clave:** Uso de `rand()` / `Math.random()` / librerías estándar del lenguaje para acotar un rango numérico
