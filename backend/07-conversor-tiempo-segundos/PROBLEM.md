# Conversor de Tiempo a Segundos

- **Concepto:** Un script de consola que recibe una cantidad en segundos (ej. `3665`) y la desglosa en formato legible: `X horas, Y minutos y Z segundos`
- **Por qué funciona:** Refuerza los operadores aritméticos fundamentales como la división entera y el operador módulo (`%`)
- **Lógica clave:** Uso de `% 60` y `/ 3600` para desagregar las unidades de tiempo
